Thai Font Kit 0.2.1 alpha — Google Fonts ภาษาไทยสำหรับเครื่องของคุณ

- เปลี่ยนไอคอนโปรแกรมเป็นแบบ Icon 02 ของผู้สร้าง และปรับสีส้ม #fd6a0d กับน้ำเงินเข้ม #031a3e ทั่วแอป
- อัปเดตไอคอนตัวติดตั้ง Windows, macOS และ Linux
- เพิ่มฟอนต์ภาษาไทยครบ 34 ตระกูล รวม 257 ไฟล์ ตามรายการทางการ Google Fonts
- เพิ่ม Google Sans, Playpen Sans Thai, IBM Plex Sans Thai Looped, Itim, Mali, Sriracha และตระกูลอื่น ๆ
- รักษาความเข้ากันได้ของข้อมูลฟอนต์เดิมทั้ง 8 ตระกูล และเพิ่มพื้นที่เลื่อนดูรายการ
- ทดลองข้อความด้วยฟอนต์จริงก่อนติดตั้ง
- ติดตั้งสำหรับผู้ใช้ปัจจุบัน และถอนเฉพาะไฟล์ที่แอปเป็นผู้ติดตั้ง
- ตรวจ SHA-256 และอักษรไทยก่อนติดตั้ง พร้อมสัญญาอนุญาต OFL

เลือก Windows x64 (.exe), macOS Apple Silicon หรือ Intel (.dmg), Linux x64 (.deb / .AppImage)

รุ่น alpha: ตัวติดตั้งยังไม่ได้เซ็นด้วยใบรับรองผู้เผยแพร่ / notarize เผยแพร่สำหรับผู้ทดสอบระยะแรก ต้องตรวจสอบบนเครื่องจริงก่อนใช้กับงานสำคัญ ไม่ใช่ปลั๊กอินอย่างเป็นทางการของ ArtCraft และยังไม่ได้รับรองความเข้ากันได้กับแต่ละแอป

เมื่อติดตั้งฟอนต์แล้ว ให้ปิดและเปิดโปรแกรมออกแบบอีกครั้ง ฟอนต์ที่ติดตั้งจะอยู่ต่อแม้ถอน Thai Font Kit หากต้องการถอนฟอนต์ด้วย ให้ถอนในแอปก่อนถอนโปรแกรม

Internet is required to download uncached fonts. Installed fonts remain available offline. There is no automatic updater or background service in this alpha.
