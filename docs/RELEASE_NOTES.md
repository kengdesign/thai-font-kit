Thai Font Kit 0.4.0 alpha — ไอคอนใหม่ สีตรงโลโก้ และลดขั้นตอนใช้งาน

- ไอคอนแผ่นฟอนต์ซ้อนตามไฟล์ของผู้สร้าง สีส้ม #FF7908 และตัวอักษรน้ำเงิน #061D40
- Windows: อัปเดตไอคอนทางลัดเดิมและแจ้ง Explorer ให้โหลดไอคอนใหม่ โดยไม่ลบแคชระบบ
- ปุ่มหลักส้มสด ตัวอักษรสีขาว รวมถึงตอนชี้เมาส์ ไม่มีโทนน้ำตาล
- ถอดตัวเชื่อม PhotoCraft ปุ่มเลือก exe ปุ่มใช้ฟอนต์ และโหมด companion ออกตามคำขอ
- คงฟอนต์ไทย 34 ตระกูล 257 ไฟล์ พรีวิวอัตโนมัติ รายการโปรด หมวด และดูล่าสุด
- คงการแก้เวลารอและสถานะติดตั้งจากรุ่น 0.3.1

แอปนี้ยังไม่ได้ฝังแท็บหรือรายการฟอนต์ภายใน PhotoCraft การทำเช่นนั้นต้องแก้ PhotoCraft เอง ไม่ใช่ติดตั้งแอปนี้แล้วเมนูจะปรากฏ

เลือก Windows x64 (.exe), macOS Apple Silicon / Intel (.dmg), Linux x64 (.deb / AppImage)
รุ่น alpha ยังไม่ได้เซ็น publisher certificate / notarize
ปิด Thai Font Kit ก่อนอัปเดต ฟอนต์ที่ติดตั้งไว้ยังอยู่ในเครื่อง
